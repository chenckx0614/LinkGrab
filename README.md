# LinkGrab

一个简洁好看的 Android 链接解析下载器。

## 功能

- **无水印下载**：粘贴抖音 / 小红书分享链接，一键解析视频、图片、图集，去水印保存到本地
- **实时状态通知**：解析 / 下载进度常驻通知栏，随时掌握
- **历史记录**：解析过的内容自动留存，随时回看再下载
- **工具箱**：视频提取音频、图片格式转换，还内置了小游戏「奶蛙消消乐」

## 界面

- 液态玻璃风格 UI，iOS 式页面转场（滑入 / 渐糊遮罩）
- 4 款底栏可切换：液态玻璃（默认）、HyperOS4、HarmonyOS7、Material 3

## 系统要求

Android 12（API 31）及以上

## 下载

前往 [Releases](https://github.com/chenckx0614/LinkGrab/releases) 下载对应架构的 APK（一般选 `arm64-v8a`）。

## 技术栈

Kotlin + Jetpack Compose + miuix，导航用 Navigation Compose，网络层 Retrofit + OkHttp。
