# LinkGrab

一个简洁好看的 Android 链接解析下载器。

## 功能

**解析下载**

- 支持抖音、小红书、B站、微博和普通网页链接，一键取无水印视频、图片、图集
- 视频可选清晰度保存，并记住上次的选择
- 图集可多选保存，支持实况照片（封面 + 视频封装成一张）
- 一次粘贴多条链接走批量解析，结果页可勾选后一键全部下载

**下载管理**

- 下载队列，可设并发数（1～4）
- 暂停 / 续传（断点续写）、失败自动重试两次
- 按平台和日期自动归档；也可用系统文件选择器指定任意保存目录
- 已完成的文件可直接打开、分享或复制保存位置

**其它**

- 历史记录：解析过的内容自动留存，支持搜索、筛选、批量删除
- 实时状态通知：解析和下载进度常驻通知栏
- 剪贴板识别：回到应用自动认出复制的分享链接
- 工具箱：音乐解析下载、视频转音频、图片格式转换、文件传输、网盘直链
- 崩溃日志留在本地，可在「关于应用」里查看并复制

## 界面

- 两套主题：液态玻璃（默认）、柔光玻璃
- 跟随系统 / 浅色 / 深色三种明暗模式
- 四种底栏样式可选

## 系统要求

Android 12（API 31）及以上。

## 下载

前往 [Releases](https://github.com/chenckx0614/LinkGrab/releases) 下载对应架构的 APK：

- `arm64-v8a`：绝大多数 64 位手机（一般选这个）
- `armeabi-v7a`：较老的 32 位设备

国内访问 GitHub 慢的话，可到 [Gitee 镜像](https://gitee.com/chenckx0614/LinkGrab/releases) 下载。

## 技术栈

- Kotlin + Jetpack Compose，导航用 Navigation Compose
- 网络层 OkHttp（部分站点走 Cronet 以匹配浏览器 TLS 指纹）
- 图片 Coil 3，视频播放 Media3 ExoPlayer
- 偏好存储 DataStore，玻璃材质基于 backdrop / capsule / shapes

## 说明

解析依赖各平台公开页面与第三方网络接口，可用性取决于平台风控和网络环境。应用只做本地解析与保存，不上传任何内容。
