## 3.3.0（379）：新增类 ColorOS 主题
用户给了两个 ColorOS 库（suqi8/coui = ColorOS 16 完整控件库，Miuix fork，KMP，Apache-2.0；
ItosEO/COUI-Kit = ColorOS 17 凝光视效，Android only，MPL-2.0），要第三个主题。

- **两个都引不了**：coui 需 Kotlin 2.4.10 / CMP 1.11.1，Kit 需 Kotlin 2.4.20 / Compose 1.12 / AGP 9.4；
  项目 Kotlin 2.3.20 / BOM 2025.06。结论与 miuix 相同，只能拷规格。详细对比见 `docs/COUI-两个ColorOS库分析.md`。
- **新知识：ColorOS 圆角是 Lp 超椭圆**，`(a^w+b^w)^(1/w)=1`，w=2.5（`CouiCornerWeight`），
  `diagonal = 0.5^(1/w)`，半角拆两段、按 0.05px 误差分段折线。**不是** miuix 的 G2 连续曲率，两套形状不能互替。
- **动效可以拿**：两个库共用 `stiffness=(2π/response)²`、`damping=1-bounce` 的 folme 参数化；
  按压缩放按**面积（20→150dp² 映射 0.85→0.97）**和**宽高比（>2 的长条另算再取均值）**，
  中间过 `PathInterpolator(0,0,0,1)`（y=3x^(2/3)-2x）。按下 response 0.25/0.3、松开 0.5 + bounce 0.6。
- **两代按压相反**：ColorOS 16（coui）卡片叠色 `pressedColor=surfaceContainerHigh`；17（Kit）是缩放。
  落地时各归各位——行/卡片叠色，按钮缩放。
- 色板关键差异：深色卡片是**半透明白 #1AFFFFFF** 叠在纯黑上，不是不透明 #242424；
  页面底亮 #F0F1F2；行高 48dp（比 miuix 56 紧）、卡片圆角 12dp（比 20 小）。
- 落地文件：`ui/coloros/{CouiShape,CouiMotion,CouiDesign,CouiEffects}.kt`；分派口 `AppVisualStyle.COLOR_OS`（=2），
  `isSystemStyle()` 用来合并「两个系统主题都不画玻璃描边」这类判断。
- 效果只做纯 Compose 能做的：卡片轮廓光（135° 渐变内描边）+ 菜单命中项聚光（径向渐变）。
  RuntimeShader 材质混色 / 自绘投影 / metaball 没接，理由写进文档。

## 3.3.1（380）：删掉 HyperOS 入场动效，修好 ColorOS 切换，补凝光效果
用户三点：「HyperOS 那个每次切换的动效删掉」「ColorOS 切换不了」「ColorOS 再做多点效果」。

- **ColorOS 切换不了的真因是两处 `coerceIn(0, 1)`**：`SettingsRepository` 里读（第 39 行）和写（第 95 行）都钳到 0..1。
  点第三张卡时 `setVisualStyle(2)` 被写成 1 → 落到 HyperOS，看起来"切换没反应"。
  **教训：加第三个枚举值时必须全局 grep `coerceIn`，写入侧和读取侧都要改**（只改读取侧仍会被写坏）。
- **删掉 HyperOS 卡片入场**：删 `ui/hyper/HyperReveal.kt`（整文件）、`HyperCard` 的 `reveal/revealIndex` 参数与
  `hyperRevealLayer`、`HyperRevealCursor` + `LocalHyperRevealCursor`、`IOS26PageScaffold` 里的 cursor 提供与
  `CompositionLocalProvider` 包裹。用户明确不喜欢每次进页面卡片逐个浮起。
- **ColorOS 补的效果**（新建 `ui/coloros/CouiSpotlight.kt`）：
  - `Modifier.couiTouchLight`：触点跟手光。用 `awaitFirstDown(pass = Initial, requireUnconsumed = false)`
    观察触摸、**不消费**，所以不抢 clickable、不影响滚动；按下 intensity/spread 走 `CouiMotion.press`，
    松手 `release`（0.5s + 0.6 回弹）扩散到控件 1.45 倍宽后淡出。深色用 `BlendMode.Plus` 提亮，浅色 `SrcOver`。
  - `Modifier.couiSheen`：顶部 62% 高度的白色渐隐，模拟"半透明材质"的受光面；画在 `drawContent` 之前。
  - `Modifier.couiAmbientGlow`：页面顶部主色环境光（暗 10% / 亮 6%，半径 1.15 倍宽），接在页面底色后。
  - 开关按 coui 尺寸重做：轨道 38×24、拇指 18、内距 3、travel 14（iOS 49×28/20/4/25/21），
    拖动阈值全改成 `travel` 的倍数；拇指加 10% 黑投影（coui ThumbShadow #19000000、下移 1dp）。
  - 下拉菜单弹入换成 ColorOS 主菜单弹簧 `spring(0.8, 322.27)`（response 0.35 / bounce 0.2），比玻璃那套更脆。
