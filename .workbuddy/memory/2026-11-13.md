## 3.4.5 柔光玻璃下关于页图标变直角（commit 见 git log）

用户反馈：柔光玻璃模式下「关于应用」的大图标是直角方块。

根因：`AboutScreen` 里 `LocalUnifiedUi.current`（柔光玻璃）分支用的是
`painterResource(R.drawable.ic_launcher_foreground)` —— 那是 adaptive icon 的**前景层**：
内容只有视口中间约 96%，四周透明边距，本身是一张直角方图，且没有背景层。
液态玻璃分支用的才是 `launcherBitmap`（背景铺满 + logo 居中合成）再 `clip` 圆角。

修复：两模式统一走 `launcherBitmap`，圆角按各自设计语言：
- 柔光玻璃：`ContinuousRoundedRectangle(20.dp)`（G2 连续曲率，和 designsystem 卡片一致）
- 液态玻璃：`RoundedCornerShape(22.dp)`（保持原样）

顺手清掉 `AboutScreen` 里重复的 `clickable` 导入和不再使用的 `painterResource`。

教训：**adaptive icon 的前景层不能当图标用**。前景只放 logo、四周留透明边距（安全区），
直接铺到 UI 上会同时丢圆角和背景。要用 `ContextCompat.getDrawable(R.mipmap.ic_launcher)`
在 Canvas 上合成（固定 512 渲染），再 clip 目标形状。

产物：dist/LinkGrab-3.4.5-arm64-v8a.apk（27,373,646，MD5 bbf92c2f0435a7f575e75ec7682eca41），versionCode 398。
