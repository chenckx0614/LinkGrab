用户从候选清单里挑了 1 3 5 6 7 10 11 12（跳过「仅 Wi-Fi」「剪贴板历史」「转 PDF」）。

**1 下载完成任务可打开/分享**
- `DownloadTaskItem` 加 `savedUri`；图片/视频/实况三条路径成功时写入成品 uri（原先成功后 partialUri 被置 null，任务行 Success 分支四个按钮全空，用户只能去相册翻）。
- `DownloadsScreen.TaskRow`：成功行整行点击=打开（ACTION_VIEW + grantRead），行尾「更多」下拉=打开/分享/复制保存位置（查 MediaStore RELATIVE_PATH+DISPLAY_NAME 拼路径）。
- 踩坑：`RowButton(icon, label, onClick, tint)` 有默认 tint 参数，尾随 lambda 会绑到 tint → 编译报「No value passed for onClick」。必须写 `onClick =`。

**3 失败自动重试**
- `runDownloadTask` 的 catch：`MAX_AUTO_RETRIES=2`、退避 1.2s/3.5s，只对 `IOException`/`HTTP 5xx`/timeout/empty response 重试（403/404 重试没意义）。
- 手动重试（resumeTask）会把 `retryCount` 清零，重新给满额度。
- 递归调用 runDownloadTask 复用当前 semaphore permit。

**5 图集解码尺寸**
- ResultScreen 五处 ImageRequest 全部加 `.size()`：缩略图 480、视频封面 720×1280、预览/hero 1600。原来按原图解码，20 张 1080×1920 就是 160MB+。

**6 解析阶段提示**
- `ParseRepository.parse(url, onStage)`：识别链接 → 获取内容 → 获取作品信息 → 打开作品页 → 尝试备用接口。
- `ParseUiState.parseStage`，MainViewModel 里 8s 未完成再补一句「站点响应慢，还在等」；首页转圈旁显示文案。

**7 自定义保存目录（SAF）**
- 新增 `data/download/SaveLocation.kt` + `androidx.documentfile:documentfile:1.0.1`。
- `SettingsRepository.customSaveTree`（DataStore 存 tree uri）；下载管理页「保存位置」行，用 `ACTION_OPEN_DOCUMENT_TREE` 自建 Intent（带 FLAG_GRANT_PERSISTABLE_URI_PERMISSION）再 `takePersistableUriPermission`。
- 图片/视频/实况三条写入路径：先试 `SaveLocation.createInTree`，失败或没设置就回退 MediaStore（用户目录被删/权限被回收不能让下载失败）。
- **关键点**：SAF 文件没有 IS_PENDING 概念 → 收尾前判断 `isMediaStoreUri(uri)`；写入循环完全复用（都是 `openOutputStream(uri, "wa"/"w")`），断点续传不受影响。半成品在自定义目录里是可见的（可接受）。
