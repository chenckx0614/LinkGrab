## v2.5.25：通知不消失修复 + 更新设置二级页
- LiveUpdatesService 通知卡死两处根因：
  ① updateLiveUpdate/finishLiveUpdate 用 notificationManager.notify() 发通知——不挂服务前台生命周期，服务 stopForeground 后迟到的 UPDATE 会发出「ongoing 但无人移除」的孤儿通知，永远划不掉。改走幂等 startForeground()。
  ② finish 的 postDelayed(2s) 无 removeCallbacks：finish 后立刻开始新一轮，旧定时器砍掉新通知。改 mainHandler + finishRunnable，onStartCommand 任何指令先 removeCallbacks；STOP/finish 兜底 notificationManager.cancel(NOTIFICATION_ID)。
- 新建 UpdateSettingsScreen（我的 → 更新设置二级页，参照用户截图 com.haooz.chedule）：当前版本 v{VERSION_NAME}、检查更新行（chevron/检查中…，结果就地显示）、「更多设置」分组：自动检查更新 + 更新提醒开关（DataStore int key auto_check_update / update_reminder，默认开）。
- 弹窗策略：手动检查发现新版本始终弹；自动检查弹不弹由「更新提醒」决定（MainViewModel.manualUpdateCheck 标记，AppNavigation 弹窗条件 UpdateAvailable && (manual || reminder)）。
- 设置页「软件更新」面板 → 一行 ListRow「更新设置」（副标题带版本号）跳转；Screen.UpdateSettings 路由 + MainTabs 增加 onNavigateToUpdateSettings。
- 编译踩坑：UpdateSettingsScreen 漏 iosSecondaryLabel import（一次）；SettingsScreen 清掉 checkingUpdate/updateResult 与 iosBlue/iosError/UpdateResult imports。
