### 3.2.20 图标返工（用户：边上一圈黑边）
- 用户反馈卡片外侧有一圈"黑边"。量了前景像素：卡片边缘是抗锯齿浅蓝，无暗色描边、无低 alpha 暗像素 → 黑边不在前景。

## 3.2.21（372）：图标彻底满幅，不再靠缩
用户装 3.2.20 后仍反馈"图标还是那样"（截图：卡片外一圈浅紫色带）。上一版把卡片缩到 57% + 背景换成同色系，本质没解决——**只要卡片小于裁切区，就必然露背景**。
- 关键量化：MIUI 只显示 108dp 画布中央 **72dp（66.7%）**。卡片 57% 时四周各露 7.5% 的背景带，任何纯色都不可能匹配卡片的蓝→紫对角渐变。
- 试过并否掉的方案：①卡片外圈 clamp 延展（把左右边缘像素拉出去）→ 猫胡须被拉成横向条纹；②Laplace 重建卡片渐变 → 卡片四角是圆角填洞色，重建出暗角；③内缩取样 clamp → 采样列穿过猫脸/相机，出现竖条纹。根因：这张卡片图四边都被内容占住（猫耳距顶 6%、胡须距边 6.7%、相机距底 3%），没有干净的背景环可采样。
- 最终方案：**卡片直接放大到 70%（超出 72dp 裁切区），让系统遮罩裁进卡片内部**，露不出任何背景；背景层改成卡片强模糊（24px→放大→blur 10）作兜底，万一某些启动器用更宽的遮罩，露出的也是同色系光晕而不是硬边。
- legacy mipmap 单独处理：老启动器不做 72/108 裁切，卡片要按 1.02 铺满再套圆角遮罩，否则会看到"卡片嵌在模糊底上"。
- 脚本 `tools/icon/build_icon.py`（参数=内容比例）：crop→fill_holes→缩放→合成→输出 foreground/background/各密度 mipmap/masked 预览。`mipmap-anydpi-v26/ic_launcher.xml` 的 background 从 @color 改成 @drawable/ic_launcher_background，colors.xml 里同名 color 删掉。
- 包内验证：res/qx.png 内容 69.7%×71.8%，res/M0.png（背景）432 全不透明。
- commit a82619c0，未推送。

### 3.2.23 补记：连续曲率的两处几何 bug（靠离线渲染才发现）
把 `HyperSquircleShape` 用 Python 按同一套数值重算并栅格化，前两版渲染出来是碎块，定位到两个问题：
1. **右上/左下角的贝塞尔终点没交换坐标**：镜像时要取 B 段起点的镜像 `(w - a1yy, a1x)`，我写成了 `(w - a1x, a1yy)`，两个角的曲线终点跑到隔壁边上，路径自交。
2. 圆弧方向一度被我改反（TR 应 290°+50、BL 应 110°+50）。镜像 x 时角度是 θ→180-θ，但**起点顺序也反过来**，容易算错，改完必须渲染验证。
验证方法固定下来：算多边形面积（260²=67600，squircle 约 64700 才对）+ 扫描线填充出图看角。注意复现脚本里坐标要用相对值，否则 p0 会被二次偏移。
