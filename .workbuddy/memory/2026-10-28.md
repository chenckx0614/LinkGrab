## 3.2.1（352）实况相册识别修复
- 用户反馈：实况保存后相册只显示普通图片。
- 根因（高概率）：MotionPhotoWriter 的 Container:Directory 里 Primary Item:Length 写死 "0"。不少相册（国产 ROM 常见）靠 Container 目录定位视频：video 起点算 = primaryLength + padding，Length=0 时算出垃圾地址 → 当纯图片。
- 修复：writer 改为缓冲 JPEG body（校验以 FFD9 EOI 结尾），Primary 长度用不动点迭代算准（长度数字位数影响 XMP 总长，2 轮收敛）；测试断言 Primary Length == 实际视频前字节数 + EOI 紧贴视频。
- 3.2.1（352）出包 dist 双 ABI，3.2.0 包已清。未推送。若用户重测仍不识别 → 问机型/相册，三星需 SEF/XTABLE 尾巴、华为私有格式，需另行适配。
