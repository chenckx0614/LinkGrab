# 2026-10-18

## LinkGrab v3.0.11

- 文叔叔改回手机页面：AppNavigation 中 `ToolWebScreen` 的 `desktop` 由 `true` 改回 `false`，不再强制 Windows Chrome UA。
- 恢复工具页右上角菜单的毛玻璃：GameScreen/WebPageScreen 中把菜单的 `layerBackdrop` 从常挂的静态纯色层改挂到内容列，菜单展开时重新模糊后面的网页内容。
- 版本号升到 3.0.11（versionCode 312），更新日志追加 3.0.11 条目。
- 编译 release 双 ABI APK，已覆盖 `dist/LinkGrab-3.0.11-arm64-v8a.apk` 与 `dist/LinkGrab-3.0.11-armeabi-v7a.apk`。

## LinkGrab v3.0.12

- 修复菜单展开后无法点击外部关闭：加入全屏透明点击遮罩（`MutableInteractionSource`，无涟漪）。
- 返回键逻辑调整：菜单开着先关菜单，再处理网页历史 / 退出。
- 修复网页闪屏/显示不全：把菜单毛玻璃的 `layerBackdrop` 从整页 Column 移到顶栏 Row，不再把 WebView 硬件视图录进采样层。
- 版本号升到 3.0.12（versionCode 313），更新日志追加条目。
- 编译 release 双 ABI APK，已覆盖 `dist/LinkGrab-3.0.12-arm64-v8a.apk` 与 `dist/LinkGrab-3.0.12-armeabi-v7a.apk`。
